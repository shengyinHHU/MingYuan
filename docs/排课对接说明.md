# 教师排课对接说明

## 当前范围

教师小程序复用若依排课服务进行增删改查，教师只能为本人新增一对一课程（`classMode=2`），一次固定两小时。管理员可新增班课。现有班课保持原有数据和展示。

星期标题与课程网格在同一个横向滚动容器内，左侧时间轴固定。周课表按实际日期、起止时间和调课记录展开；日期或重复规则缺失时显示待排。

## 教师小程序接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/miniapp/teacher/course/schedules` | 本人排课及调课记录 |
| GET | `/miniapp/teacher/course/schedule/{id}/edit` | 本人排课编辑资料 |
| POST | `/miniapp/teacher/course/schedule` | 新增本人一对一课程 |
| PUT | `/miniapp/teacher/course/schedule` | 修改本人排课 |
| DELETE | `/miniapp/teacher/course/schedule/{id}` | 删除无业务引用的本人排课 |

时间使用 `HH:mm:ss`；开课、结课日期使用 `yyyy-MM-dd`。每周规则为 `WEEKLY`（明确的周一至周日），暑期规则为 `DAILY_5_1`（上五天休一天）。教师身份由后端固定，不能传其他教师账号；报名人数由报名业务维护。排课编码新增自动生成，修改不可变更。

有签到历史时不得直接改写授课时间、日期、教师、教室或授课形式，应走现有调课流程。有报名、考勤、调课或作业引用的排课不能删除，可停用并保留历史。

## 一对一协作分工

| 负责人 | 工作 |
| --- | --- |
| 本功能分支 | 排课管理、一对一报名、费用统计 |
| 其他同学 | 开放时段、学员约课、课包记次与扣次、付款 |

本轮没有实现支付、扣课或新增课包表。后续报名与费用统计应对接队友的实际预约、课包和支付数据；未提供金额时显示“暂未提供”，不能把缺失金额当作零元。

`classMode=2` 表示排课授课形式，本身不表示已开放预约、已付款或已扣课。预约开放与预约写入仍须校验占用；未排课程和未经核验的空白区域不能用于承诺可预约。新增预约写入方应与排课、调课写入方统一并发占用规则。

## 验证与启动

后端离线编译、10 项 CRUD／日历／MyBatis 场景及微信 WXML 模板编译通过。实际 MySQL 写入及微信滑动交互仍需联调。新增接口需要通过本机原有启动脚本停止旧后端、重新构建并启动后生效；禁止覆盖运行中的 JAR。

本机配置、数据库数据和备份不纳入提交。

## 简化的一对一创建参数

教师小程序 POST 创建仅需 `classroomId`、`gradeName`、`courseClassName`、`subjectName`、`startDate`、`startTime`、`weeks`（1至52）。后台固定本人教师、一对一类型及两小时，按开始日期的星期每周一次，最后课次日期为开始日期加上 `(weeks-1)*7` 天。默认持续一周。暂不支持跨午夜排课，开始时间需早于22:00。

创建页不要求填写课程年份、学期、期次、时段、班型、结束日期或招生状态。上述字段由后端映射到已有排课表，不新增业务表。为避免原若依网格唯一键把不同开始日期的时段误判为同一格，简化创建的学期定位为“一对一+首课日期”；真实日期冲突仍由共享服务校验。

学科默认取本人已有课程的学科，无已有课程时取字典首项，可修改。现有教师资料未发现资深等级字段；本创建接口不接受资深等级，不根据教师姓名或班型猜测等级，也不实现付款、扣课或费用倍率。等级来源应由后台与负责相关业务的同学对接。

# 家长孩子中心调整说明

## 页面组织

家长首页的“我的账户”和原孩子资料入口复用同一套页面：先展示孩子卡片及“添加孩子信息”，点击孩子进入详情。孩子姓名、年级、可用额度和待办优先显示。

孩子详情包含待办事项、课程、学习记录、课包与费用、基本资料。添加和编辑复用原弹层及 `LessonCreditService`，删除继续执行已有业务引用保护。

商城订单、优惠券和邀请好友属于家长账号，在账户首页的“家长服务”中进入。老带新的推荐码、推荐关系、新老角色和奖励资格均不按孩子拆分。

## 身份与额度

- 孩子沿用现有课次账户 `accountId` 作为页面上下文，后端确认其 `parent_id` 属于当前家长；报名关联沿用 `lesson_account_id`、`student_id`，不按姓名、年级或电话猜测。
- 从孩子进入报名、课表、作业、请假、账单、收据和退款时保留该孩子。没有指定孩子的旧调用保持原家长账户范围，兼容已有入口。
- 同名孩子、同班兄弟姐妹的作业使用具体 `enrollmentId` 区分，提交前再次核对其家长、孩子和作业所属课程。
- 可用额度按“剩余额度－预约暂占”计算。每次一对一固定两小时，精英教师消耗一个额度、资深教师消耗两个额度，因此额度不等于可上课节数。
- 改名仅修改当前孩子资料；旧报名、考勤、财务及收据的原姓名快照保留。

## 待办和进度

本轮家长待办仅统计两类可操作事项：

| 待办 | 条件及操作 |
| --- | --- |
| 待缴费 | 有效单次付费报名已经核价、未支付且没有待确认、未知或成功收款；进入账单后联系教务线下缴费。 |
| 待交作业 | 有效报名对应已发布、未归档且未过期的作业，该报名尚未提交；按钮进入该孩子的待提交列表。 |

待缴费按报名记录统计，作业按作业和报名的组合统计。待老师审核、待管理员确认收款、待核价、退款处理中均为进度，不计家长待办。管理员原待登记收款数量与接口语义保留。

孩子卡片显示各自待办数字；首页“我的账户”数量合计家长待办，原角色切换及迟到响应防护继续有效。页面返回和下拉刷新会重新查询。

## 未关联历史

未关联孩子的报名及其缴费详情独立放在账户首页。只允许管理员通过原核对关联服务填写原因后关联，保留操作历史。选择某个孩子不会归入历史记录。商城订单不归孩子。

## 兼容扩展

| 接口或服务 | 本轮变更 | 兼容方式 |
| --- | --- | --- |
| `GET /miniapp/parent/account` | 孩子增加课程数及可操作待办计数 | 原字段保留；原待登记付款数量不改语义。 |
| `GET /miniapp/parent/account/children/{id}` | 当前家长的单个孩子及汇总 | 复用原账户表，无额外账户来源。 |
| `GET /miniapp/parent/account/records` | 可选 `accountId` 或 `unlinkedOnly`，增加考勤视图 | 两种范围互斥；旧调用保持原范围。 |
| `GET /miniapp/parent/account/pending-count` | 可选 `actionable=true` | 不传参数时保留原计数。 |
| 家长报名、课表、请假、作业查询 | 可选 `accountId` | 后端校验归属，再按可靠关联筛选。 |
| 作业详情及提交 | 可选 `enrollmentId`、`accountId` | 原签名及未指定孩子的调用保留；明确指定报名时不再替换为同班其他孩子。 |
| `TuitionService` 账单、退款与归属校验 | 可选 `accountId` | 原收款、退款、财务版本与请求幂等流程保留。 |
| `TuitionReceiptService` 收据列表 | 可选 `accountId` | 保留原查询和收据快照、下载权限，不重写财务历史。 |

本轮不新增表、不改表结构、不修改 `sys` 表，不执行数据库迁移，不生成业务测试数据到实际库。本机地址修复、微信开发配置及已有未提交修改保留；数据库备份在仓库外。

## 验证

孩子中心在实际数据库的独立副本验证同名孩子隔离、作业提交、课包暂占与资深双倍消耗、账单和收据归属、请假范围、改名快照及引用删除保护。前端验证孩子上下文保留、待办与进度区分、未关联历史分离和迟到响应隔离；使用微信原生编译器检查模板及共享样式。

本轮完整后端 98 项、小程序 176 项、网页 77 项测试通过；51 个注册页面的模板和孩子中心共享样式原生编译通过。已启动更新后的后端，并用已有孩子的家长账号核验实际接口及跨家长访问拒绝；教师、管理员和家长原有接口回归正常。实际数据库 75 张表在构建前后逐表核验数据不变。

微信开发者工具中的实际视觉效果仍需在编译后查看；模板编译不等于真机交互验收。

## 主页统一切换孩子

家长主页改为“孩子姓名 ▾ 家长，欢迎您”，点击姓名展开孩子列表，显示姓名、年级、当前选中状态和待办数字；列表提供“添加孩子信息”。添加仍打开已有账户资料表单，成功后选中新孩子并返回主页。

当前孩子只保存稳定账户编号，按后端地址和家长账号分别记忆；教师、管理员不读取该选择。账户页仍管理全部孩子，进入另一孩子详情会同步切换主页。删除后重新核对可选名单；未关联历史继续属于家长账号。

家长课程入口、首页近期课程、作业、考勤、请假、课包和课程费用均带入当前孩子。没有孩子时引导到已有添加表单；页面返回时发现选择变化，会清空旧内容并进入新孩子的列表，旧报名或账单详情不会被当成新孩子记录。统一请求层拒绝孩子不一致的请求并丢弃过期响应；未关联历史费用使用明确的家长范围，仍检查家长身份变化。

首页移除固定课时数字及示例课程：显示当前孩子的可用额度、已报课程数和可操作待办。近期课程按可靠排课日期显示，缺少日期不编造课程；失败显示重试信息。

考勤接口增加可选 `accountId`，明细配合 `enrollmentId` 校验；旧调用不变。孩子范围按实际签到、已完成一对一及可靠历史到课记录展示，按报名编号区分同名班次，不把自动生成的空考勤当作真实课次。报名、取消及请假请求也再次核对可选孩子上下文。本轮不改数据库结构。

主页切换回归通过：186 项小程序、98 项后端测试，实际库独立副本的同名孩子/考勤/财务/作业验证，以及运行中后端的孩子访问范围与原有接口检查。56 个 WXML/WXS 资源、61 个 WXSS 资源完整依赖编译通过；微信工程文件索引已刷新。未提交 Git 或创建 PR。
